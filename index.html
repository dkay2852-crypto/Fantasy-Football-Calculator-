Values load from FantasyCalc’s public API (https://api.fantasycalc.com/values/current with isDynasty, numTeams, numQbs (1 or 2 for Superflex), and ppr=1. Trade values use FantasyCalc’s ~1–10,000 scale (elite assets can slightly exceed 10,000). Draft picks cover the next three NFL drafts, rounds 1–5. When FantasyCalc omits a round (often 5ths, and all picks in redraft), SNAP extrapolates from nearby FantasyCalc pick values so league-size and format still move the numbers.
